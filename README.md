# คืนลอย — ลอยกระทง & ลอยโคมออนไลน์ โดย Mattiw

เว็บภาษาไทย Django + SQLite ไม่ต้องล็อกอิน รองรับมือถือและคอมพิวเตอร์ มีหน้าลอยกระทง `/` และหน้าลอยโคม `/lanterns/` แยกสระ/ท้องฟ้าและข้อมูลกัน

## เริ่มใช้งานบน Windows

ต้องมี Python 3.10 ขึ้นไป (ทดสอบด้วย Python 3.12)

```powershell
cd 'D:\ลอยกระทง'
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

เปิด http://127.0.0.1:8000 และกด Ctrl+C เพื่อหยุดเซิร์ฟเวอร์ สคริปต์จะสร้าง virtual environment ติดตั้ง dependencies และเตรียมฐานข้อมูลในการรันครั้งแรก

หรือรันเอง:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

ดูบนมือถือที่เชื่อม Wi-Fi เดียวกัน โดยแทน IP ด้วย IPv4 ของคอมพิวเตอร์ (ดูจาก `ipconfig`):

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 -LanIP 192.168.1.20
```

จากมือถือเปิด `http://192.168.1.20:8000` อนุญาต Python ผ่าน Windows Firewall สำหรับเครือข่ายส่วนตัวเมื่อระบบถาม

## ความสามารถ

- สระกลางคืนขนาดใหญ่ มีพระจันทร์ โคมลอย แสงเทียน และภาพเคลื่อนไหว
- กระทง 18 แบบ พร้อมตัวกรองหมวด: ดั้งเดิม (บัวชมพู ใบตอง บัวทอง ดาวเรือง เรือ), สัตว์ (เป็ด หงส์ เต่า แมว กระต่าย แพนด้า คาปิบารา), ของกิน (แตงโม กะลามะพร้าว ขนมปัง), อื่น ๆ (หัวใจ พระจันทร์ ดาว) พร้อมโคมลอย 3 สี
- เลือกภาพวัตถุเพิ่มเติมที่แอดมินอัปโหลด และดูตัวอย่างก่อนปล่อย
- โหมด **แต่งเอง · Custom**: เลือกสีดอกไม้ สีใบตอง รูปแบบใบตอง 4 แบบ จำนวนธูป/เทียน สีเทียน และดอกไม้/ไข่มุก/โบว์ ดูตัวอย่างทันทีและบันทึกแบบไว้กับกระทง
- อัปโหลดรูปใบหน้าแสดงบนกระทง พร้อมตัวอย่างก่อนลอย
- ชื่อไม่บังคับ คำอธิษฐานสูงสุด 280 ตัวอักษร
- กดลอยแล้วกระทงปรากฏในสระทันที แตะเพื่ออ่านชื่อ รูป และคำอวยพร
- เลือก **ลอยเดี่ยว / ลอยเป็นคู่** ลอยคู่สร้างรอบและลิงก์เชิญเฉพาะสำหรับอีกหนึ่งคน ทั้งสองใส่รูปและเขียนคำอวยพรแยกกัน กระทงหรือโคมแสดงข้างกัน
- คัดลอกลิงก์คำอธิษฐานเพื่อแชร์ เปิดคำอธิษฐานเก่าได้แม้ไม่อยู่ในสระแล้ว
- อัปเดตสระทุก 15 วินาที แสดงกระทงล่าสุดสูงสุด 80 ใบเพื่อควบคุมประสิทธิภาพ
- การ์ดผู้ลอยล่าสุดเลื่อนวนด้านล่าง แสดงรูป ชื่อ คำอวยพร เวลา และป้ายลอยคู่ กดพักหรือวางเมาส์บนการ์ดเพื่อหยุดอ่านได้
- ฉากวัดไทยริมน้ำที่สร้างด้วย ImageGen พร้อมเงาสะท้อนจริงและการเคลื่อนไหวของผิวน้ำด้วย Canvas แตะน้ำให้เกิดวงคลื่นได้ (ระบบลดการเคลื่อนไหวจะใช้ภาพนิ่ง)
- ฉากเปิดตัวหลังปล่อย: แสงเรือง วัตถุลอยขึ้น/ลอยลงน้ำ การ์ดคำขอ และพลุ Canvas หลายชุดประมาณ 7 วินาที
- ใช้ฟอนต์ Sarabun ภาษาไทยทั้งหัวข้อและข้อความ พร้อมคำบนเว็บแบบสั้น ๆ มีคำอธิษฐานให้เลือก และเครดิต “สร้างโดย Mattiw”
- เครื่องเล่นเพลงเปิด/พักเพลง ปรับความดังได้ ใช้เพลงจาก Django admin ร่วมกันทั้งสองหน้า ถ้ายังไม่มีเพลงจะใช้เสียงบรรยากาศที่สร้างด้วย Web Audio
- ปุ่มขยายฉากเต็มจอ
- ปุ่มดาวน์โหลดภาพกระทง/โคมพร้อมรูป ชื่อ คำอธิษฐาน และเครดิต **mattiw · conne** เป็น PNG ขนาดโพสต์ 1080×1350 หรือสตอรี่ 1080×1920
- ปุ่มแชร์ Facebook ผ่านลิงก์คำอธิษฐานที่มีภาพ Open Graph และปุ่ม Instagram ผ่านเมนูแชร์ไฟล์ของอุปกรณ์ พร้อมทางเลือกดาวน์โหลดภาพ
- UI responsive, keyboard navigation, รองรับ prefers-reduced-motion
- ฟอนต์ไทยเก็บในโปรเจกต์ ใช้งานได้โดยไม่เรียก Google Fonts ขณะเปิดเว็บ

สระเริ่มต้นว่าง ไม่มีข้อมูลคำอธิษฐานสมมติ กระทงกลางสระที่ระบุ “กระทงของคุณ” เป็นตัวอย่างก่อนกดลอย จึงยังไม่นับเป็นกระทงจริง ทุกคำอธิษฐานที่ส่งจะบันทึกลง SQLite และยังอยู่หลังรีสตาร์ต

## ดาวน์โหลดและแชร์กระทง

เมื่อลอยแล้วจะมีการ์ด **กระทงของเรา / โคมของเรา** ใต้ฟอร์ม หรือแตะวัตถุในฉากเพื่อเปิดรายละเอียดและปุ่มแชร์ เลือกภาพโพสต์หรือสตอรี่ก่อนดาวน์โหลดได้ แบบที่แต่งเองและรูปใบหน้าจะตรงกับวัตถุที่บันทึกไว้

ลิงก์แชร์สาธารณะใช้ `/wish/<uuid>/` โดยส่ง Open Graph title, description และรูป PNG จากเซิร์ฟเวอร์โดยตรง ไม่ต้องรัน JavaScript เพื่ออ่านข้อมูล รูปอยู่ที่ `/wish/<uuid>/card.png?layout=post` หรือ `layout=story` เพิ่ม `download=1` เพื่อดาวน์โหลด

Facebook เปิดหน้าต่างแชร์ลิงก์ให้ผู้ใช้เป็นคนโพสต์เอง ภาพตัวอย่างต้องอยู่บนโดเมนสาธารณะที่ Facebook เข้าถึงได้ `127.0.0.1` และ IP ในวง LAN ใช้ให้ Facebook ดึงรูปไม่ได้ ดู [เอกสาร Open Graph ของ Meta](https://developers.facebook.com/documentation/sharing/webmasters)

Instagram ใช้ Web Share API ของเครื่องเพื่อส่งไฟล์ภาพให้ผู้ใช้เลือกแอปเอง ต้องเป็นเบราว์เซอร์/เครื่องที่รองรับและบริบทปลอดภัย (HTTPS หรือ localhost) ถ้าแชร์ไฟล์ตรงไม่ได้ เว็บจะดาวน์โหลด PNG และมีปุ่มเปิด Instagram ให้เลือกภาพลงโพสต์/สตอรี่เอง ไม่มีการโพสต์อัตโนมัติ ดู [เอกสาร Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)

`resvg-py` มี wheel สำหรับ Windows และเป็น dependency ใน `requirements.txt` ใช้ฟอนต์ Sarabun ที่อยู่ในโปรเจกต์เพื่อจัดรูปภาษาไทย ภาพแคชในหน่วยความจำ 5 นาที ไม่ต้องติดตั้ง Node บนเซิร์ฟเวอร์จริง

## ลอยคู่และลิงก์เชิญ

1. คนแรกเลือก **ลอยเป็นคู่** ใส่รูป เลือกกระทง และเขียนคำอวยพร แล้วกด **ลอยแล้วสร้างลิงก์ชวนคู่**
2. คัดลอกลิงก์จากการ์ดด้านข้าง ส่งให้อีกคน ลิงก์มีรูปแบบ `/couple/<random-token>/` ใช้งานรับคู่ได้ 7 วัน
3. อีกคนเปิดลิงก์ จะเห็นรูปและกระทงของคนชวนอยู่ข้างตัวอย่างของตัวเอง จากนั้นใส่รูป เลือกกระทงและเขียนคำอวยพรแยก
4. พอเข้ามาครบสองคน สระของทั้งคู่จะแสดง **กรอบลอยคู่** มีกระทงสองใบ ชื่อ และปุ่ม **กดลอยพร้อมกัน** ทั้งสองคนต้องกดภายใน 20 วินาที (กดซ้ำเพื่อยกเลิกได้)
5. เมื่อกดครบ เซิร์ฟเวอร์กำหนดเวลาลอยร่วมกัน (`launch_at`) ทั้งสองเครื่องนับ 3 2 1 ตรงกันโดยชดเชยนาฬิกาจาก `server_now` แล้วกระทงค่อย ๆ ลอยออกจากกลางสระ พร้อมพลุรูปหัวใจ คำอวยพรของทั้งสองคน และคำอวยพรจากระบบ
6. กระทงคู่จะขึ้นสระสาธารณะหลังถึงเวลาลอยเท่านั้น เมื่อเปิดคำอธิษฐานจะแสดงของทั้งสองคนแยกกัน

API ลอยพร้อมกัน: `POST /api/couples/<token>/ready/` ส่ง `ready=1` (กด) หรือ `ready=0` (ยกเลิก) ใช้ได้เฉพาะคนชวนและคนที่เข้าร่วมใน session นั้น สถานะห้อง (`stage`) มี `waiting`, `gathering`, `countdown`, `launched`, `expired`

กระทงทุกใบในสระลอยเลื่อนจากซ้ายไปขวาวนต่อเนื่อง ใบที่อยู่ไกลเล็กกว่าและช้ากว่า วางเมาส์หรือแตะค้างเพื่อหยุดอ่านได้ ระบบลดการเคลื่อนไหวจะหยุดการลอยเลื่อน

แต่ละรอบรับอีกคนได้เพียงหนึ่งคน ใช้ธุรกรรมและ unique constraint กันการเข้าร่วมซ้ำ คนชวนใช้ช่องคู่ของตัวเองไม่ได้ และบุคคลที่สามเขียนทับไม่ได้ Token เชิญไม่อยู่ใน feed สาธารณะ ระบบจำคนชวนและคนเข้าร่วมด้วย anonymous Django session โดยไม่ต้องมีบัญชี ลิงก์ที่หมดเวลา/ลอยครบแล้วยังเปิดดูได้ แต่เพิ่มคนใหม่ไม่ได้ ต้องใช้เบราว์เซอร์เดิมเพื่อให้ระบบจำบทบาทเดิมได้

ลิงก์จาก `127.0.0.1` เปิดได้เฉพาะเครื่องนั้น หากส่งให้มือถือหรือเครื่องอื่น ให้เริ่มเว็บผ่าน `run.ps1 -LanIP <IP ของคอม>` แล้วเปิดเว็บด้วย IP นั้นก่อนสร้างลิงก์ หรือใช้โดเมนที่เผยแพร่จริง

ภาพฉากใช้ built-in ImageGen เก็บไฟล์ไว้ในโปรเจกต์แล้ว พรอมป์ต์เต็มและที่มาอยู่ใน `static/pond/ASSET-NOTES.txt` ภาพไม่ได้เป็นหลักฐานของสถานที่หรือเหตุการณ์จริง

รูปและข้อความเป็นข้อมูลสาธารณะตามข้อความแจ้งก่อนส่ง รับ JPG/PNG/WEBP สูงสุด 5 MB และ 20 ล้านพิกเซล เซิร์ฟเวอร์อ่านรูปจริง ตัดเป็น 480×480 บันทึกใหม่เป็น JPEG ด้วยชื่อสุ่ม และไม่เก็บ EXIF ระบบใช้ CSRF, honeypot และจำกัดการส่ง 10 ครั้งต่อนาทีต่อ IP ในแต่ละ process ข้อความจากผู้ใช้แสดงด้วย `textContent` เพื่อป้องกันการแทรก HTML

สำรองทั้ง `db.sqlite3` และโฟลเดอร์ `media` คู่กัน หยุดการเขียนข้อมูลขณะคัดลอก หรือใช้คำสั่ง backup ของ SQLite

## ทดสอบ

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
```

ทดสอบการลอยแบบไม่ล็อกอิน, CSRF, ข้อความ, รูปภาพเสีย/ใหญ่เกิน, การแปลงรูปและลบ EXIF, rate limit, ขนาด feed และลิงก์คำอธิษฐานเก่า โดยไม่แก้ข้อมูลจริง

## อัปโหลดเพลงลอยกระทงผ่าน Django admin

หน้าเว็บมีป๊อปอัปต้อนรับเป็น **Mattiw แมวส้มถือกระทง** แสดงเฉพาะการเข้าครั้งแรกบนเบราว์เซอร์นั้น เมื่อปิดแล้วจะจำไว้ใน localStorage (ใช้ cookie สำรองถ้า localStorage ใช้ไม่ได้) กด **สร้างโดย Mattiw** ท้ายหน้าเพื่อเปิดดูซ้ำได้ ลิงก์แชร์คำอธิษฐานจะเปิดคำอธิษฐานก่อนและไม่ถูกป๊อปอัปบัง

หน้า Django admin ใช้ธีม Mattiw สีส้ม–เขียว มีรูปแมวส้มในหน้าเข้าสู่ระบบ เมนูลัดจัดการเพลง แบบกระทง/โคม และคำอธิษฐาน รองรับ light/dark mode ของ Django และมือถือ สิทธิ์ผู้ดูแลและระบบล็อกอินใช้กลไก Django เดิม

สร้างบัญชีผู้ดูแลครั้งแรก:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

เปิด http://127.0.0.1:8000/admin/ แล้วเข้าสู่ระบบผู้ดูแล เลือก **เพลงประจำเว็บ → เพิ่ม** ใส่ชื่อเพลง แนบไฟล์เพลงลอยกระทงที่มีสิทธิ์ใช้งาน และติ๊ก **เปิดใช้งานเพลง** จากนั้นบันทึก แล้วรีเฟรชหน้าสาธารณะ เพลงจะอยู่ในเครื่องเล่นทั้งหน้ากระทงและหน้าโคม กด Play เพื่อเริ่มฟัง (ไม่บังคับ autoplay)

รองรับ MP3, WAV, OGG, M4A สูงสุด 30 MB แนะนำ MP3 เพื่อให้เล่นได้กว้างที่สุด มีเพลงประจำเว็บได้หนึ่งรายการ แก้ไขรายการเดิมเพื่อเปลี่ยนเพลง โครงการไม่ได้แนบเพลงลอยกระทงฉบับบันทึกเสียงสำเร็จรูปมาให้

ผู้เข้าชมลอยกระทงและโคมได้โดยไม่ต้องล็อกอิน บัญชีผู้ดูแลใช้เฉพาะ `/admin/` เท่านั้น การติดตั้งใหม่ใช้ `createsuperuser` โครงการไม่ฝังรหัสผ่านผู้ดูแลไว้ในซอร์สโค้ด

## เพิ่มกระทงหรือโคมเป็นภาพวัตถุเอง

ใน admin เลือก **แบบกระทง / โคม → เพิ่ม** ตั้งชื่อ เลือกประเภท แนบภาพและเปิดให้เลือก แนะนำ PNG/WEBP พื้นหลังโปร่งใส สูงสุด 5 MB ระบบแปลงเป็น PNG อย่างปลอดภัย ย่อให้ไม่เกิน 960×800 และรักษาความโปร่งใส

ตั้งตำแหน่งใบหน้าแนวนอน/แนวตั้งเป็นเปอร์เซ็นต์ของกรอบภาพและขนาดใบหน้าได้ เช่น X=50, Y=42, ขนาด=30 วัตถุจะปรากฏเป็นตัวเลือกพร้อมรูปตัวอย่างในหน้าประเภทนั้นหลังรีเฟรช ตัวเลือกที่ปิดใช้งานจะเลือกส่งใหม่ไม่ได้ คำอธิษฐานเก่าที่ใช้แบบนั้นยังแสดงภาพเดิมได้

แบบในเว็บเป็นภาพวาด SVG/CSS และวัตถุรูปภาพที่เลือกได้ ไม่ใช่โมเดล 3D แบบหมุนกล้อง

## การนำขึ้นเซิร์ฟเวอร์จริง

โครงการนี้เป็น Django ที่ต้องมี Python server และพื้นที่ดิสก์ถาวรสำหรับ SQLite/รูปภาพ ยังไม่ได้เผยแพร่เป็นเว็บไซต์สาธารณะ ไม่รองรับการ deploy เป็น static site หรือ Cloudflare Worker โดยตรง

1. ตั้ง `DJANGO_DEBUG=0`, `DJANGO_SECRET_KEY` เป็นค่าสุ่มยาว และ `DJANGO_ALLOWED_HOSTS` เป็นชื่อโดเมนจริง (ดู `.env.example` ซึ่งเป็นเพียงตัวอย่าง ต้องตั้ง environment variables เอง)
2. รัน `python manage.py migrate` และ `python manage.py collectstatic --noinput`
3. รัน `waitress-serve --listen=127.0.0.1:8000 loykrathong.wsgi:application` ด้วย process manager
4. ใช้ Nginx/Caddy เป็น HTTPS reverse proxy ให้บริการ `/static/` จาก `staticfiles/` และ `/media/` จาก `media/` โดยห้าม execute ไฟล์ในโฟลเดอร์อัปโหลด กำหนด upload body limit 6 MB สำหรับ API สาธารณะ และ 32 MB สำหรับ `/admin/` ที่ต้องแนบเพลง
5. ใช้ HTTPS ถึง upstream ด้วย หรือกำหนด trusted proxy ให้ตั้งค่า `wsgi.url_scheme=https` อย่างถูกต้อง เช่น Waitress `--trusted-proxy=127.0.0.1 --trusted-proxy-headers=x-forwarded-proto` พร้อม reverse proxy ที่เขียนทับ header นี้เอง อย่าเชื่อถือ header จากภายนอกโดยตรง
6. ตรวจ `python manage.py check --deploy` ภายใต้ environment จริง กำหนด HSTS ตามโดเมน และ backup ข้อมูลสม่ำเสมอ

SQLite เหมาะกับการรันบนเครื่องเดียว หากขยายหลาย process/เครื่อง ให้ใช้ rate limiter ที่แชร์สถานะได้และวางแผนฐานข้อมูล/ที่เก็บรูปให้เหมาะกับโหลด
